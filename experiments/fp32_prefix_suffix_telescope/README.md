# Fixed CPU-prefix / GPU-suffix telescope

Prospective diagnostic for the existing FP32 `layer.9.v[112,14,2]` failure. This directory does not edit the model, existing experiments, original traces or frozen numerical policy. No Rust build, generation or full model evaluation is involved. Preparation and GPU execution require separate coordinator releases; the current implementation task permits source guards only.

`C0` is the complete saved CPU embedding, and `Cb` is the complete CPU hidden state after blocks `0..b-1`. Every state has 144 rows and width 768. Define `Eb = V9(GPU blocks b..8(Cb))`, where `V9` comes from the complete native layer9 RMS/QKV operation. `A` and `D` are the original GPU and CPU V9 endpoints. The offline calculation promotes the saved FP32 endpoints to FP64 and reports

```
D - A = (E0 - A) + sum(E[b+1] - E[b], b=0..8) + (D - E9).
```

These are fixed-order conditional substitutions through a nonlinear suffix. They are not independent kernel causes. The report preserves signed terms, cancellation, per-row/global max and RMS, the original worst coordinate and FP64 closure. Signed fractions may be negative or greater than one; max/RMS are not additive. The original bound `0.005096435546875` remains unchanged and is used descriptively only.
